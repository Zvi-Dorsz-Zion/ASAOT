# ניהול קו הרישום להסעות בית השם — אפליקציית אנדרואיד

אפליקציית אנדרואיד מודרנית (Kotlin + Jetpack Compose) שמבצעת בדיוק את מה
שהתוכנה המקורית של Python/Tkinter עשתה, מול אותו שרת API
(`www.call2all.co.il`), ללא שום קובצי נתונים נלווים — הכל בקוד עצמו.

## מה האפליקציה עושה

עבור כל אחת מהשלוחות 2-5:

- **לפתיחת השלוחה** — חלון שבו ממלאים מספר מקומות, תאריך סגירה (כולל כפתור
  "יום שישי הקרוב" ובורר תאריך), ושעת סגירה (שעה/דקה/שנייה). בלחיצה על
  אישור מתבצעת בדיוק אותה סדרת קריאות API כמו בתוכנה המקורית: ניקוי
  התבנית (לשלוחות 2-4), עדכון השלוחה, ומחיקת קבצים שיוריים.
- **להורדת הדוח** — מוריד CSV מהשרת ושומר אותו בתיקיית ההורדות של המכשיר.

## איך לבנות את ה-APK דרך GitHub

1. צרו repository חדש (פרטי, מומלץ — כי בקוד יש טוקן API) והעלו אליו את
   כל תוכן התיקייה הזו (לא רק את הזיפ עצמו).
2. בכניסה ל-repository עברו ללשונית **Actions** ואשרו הפעלת workflows אם
   מתבקש.
3. ה-workflow `.github/workflows/build.yml` ירוץ אוטומטית עם כל push
   ל-branch `main`/`master`, או שאפשר להריץ אותו ידנית דרך "Run workflow".
4. בסיום הריצה (כ-3-5 דקות), גללו למטה לעמוד ה-run ותמצאו קובץ
   **Artifacts** בשם `app-debug-apk` — זהו קובץ ה-APK להתקנה על המכשיר.

> ה-workflow מייצר את ה-Gradle wrapper אוטומטית בזמן הריצה, כך שלא צריך
> לצרף קבצי wrapper בינאריים ל-repository.

## התקנה על מכשיר אנדרואיד

הורידו את ה-APK מה-Artifacts, העבירו למכשיר, ואפשרו "התקנה ממקורות לא
ידועים" בהגדרות אם מתבקש. גרסת אנדרואיד נדרשת: 10 (API 29) ומעלה.

## מבנה הפרויקט

```
app/src/main/java/com/transport/beithashem/
  MainActivity.kt   – כל ממשק המשתמש (Jetpack Compose)
  ApiClient.kt       – כל קריאות ה-API לשרת call2all
```

## הערת אבטחה

הטוקן של ה-API מוטמע בקוד (בדיוק כפי שהיה בתוכנה המקורית ב-Python).
מומלץ לשמור את ה-repository כפרטי כדי שהטוקן לא ייחשף.
